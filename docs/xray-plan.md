# BuildMe 分批实施计划

更新：2026-10-05。以 [PRD](./prd-xray-capabilities-compare.md) 为需求基准，以 [实际交付与验收](./xray-progress.md) 为进度依据。

## 执行方式

每轮开始先列出少量具体功能、相关文件与验收条件，再实施。功能以真实运行链路为准，界面、持久化、运行时效果和出错状态一起考虑。未验证的部分保留明确边界；通过本批验收后停止扩展范围，报告结果和下一批。里程碑完成时运行 PRD 指定的五项检查并提交本地 Git，不自动发布或推送。

保留现有 Cordis / Loader / Include / Profile / Bundle 和两个引擎。复用 Trace、提示词快照和公共讲解文案，避免为界面增加重复的执行链。原有未提交改动单独保留。

## 已完成阶段

- M0：统一 Trace、持久化、脱敏和能力事件采集。
- M1：统计入口、实时抽屉、四个检查页、本地讲解。本轮完成最后一批与桌面验收。

## 下一阶段：M2 能力开关

### 第一批：能力定义和运行时过滤

交付 `src/core/capabilities.ts` 唯一注册表；在运行选项与工具作用域传递能力快照；处理 workflow / subagents 依赖。桌面界面在后续批次接入，第一批不显示尚无实际效果的开关。

验收：遍历所有能力，核对允许的工具集合；不传 capabilities 时保持现有行为；core 不可移除；workflow 自动开启 subagents，关闭 subagents 同时关闭 workflow。子 Agent 的能力继承规则依据源码与 PRD 核实后写入本批计划，不让委派绕过关闭的能力。

### 第二批：提示词与压缩行为

将能力用法拆成有来源标识的独立段落，复用当前提示词注册表；工具列表、提示词与实际运行能力一致。接通 compaction 关闭时直接放行与 overflow 事件。同步调整 DSH 提示词拼装。

验收：能力关闭后对应工具和指令都消失，重新开启后恢复；两回合快照差异正确；小上下文下触发真实 overflow；DSH 提示词完整，相关现有测试通过。

### 第三批：用户可操作的能力面板

接入桌面配置、首次选择与「我的 Agent」面板；显示九项开关和五项完全体专属说明；共享知识文案；示例只填入输入框；从 Trace 读取实际使用次数。锁定卡的对比入口与 M4 的依赖明确记录，不能用假对比冒充完成。

验收：运行中切换不改变当前回合，下一回合生效；重启保持；依赖变化有提示；首次选择、示例、超限提示和浅深主题/键盘操作可用。结合真实 Electron 检查配置 → 运行 → Trace → X 光提示词差异的完整链路，关闭 M1 B-5 中能力开关联动的跨里程碑检查项。

M2 收尾逐条核对 C-1 至 C-10；必要时拆成更多轮，不为赶进度合并未经验证的功能。
